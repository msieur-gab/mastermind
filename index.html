How to Play

  • Find the secret 4-color code in 10 attempts.
  • Select colors from the palette, then submit your guess.
  • White = correct color, correct position
  • Gray = correct color, wrong position
  • Duplicates: When on, the same color can repeat in the code.
  • Scoring: 5 points for solving + 1 bonus per unused attempt.
